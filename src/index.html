⬡ 버블 정렬 Bubble Sort

▾
0 / 0 단계

{ } 슈도코드
  1. procedure bubbleSort(A)
  2. n ← length(A)
  3. for i from 0 to n-1 do
  4. for j from 0 to n-i-2 do
  5. if A[j] > A[j+1] then
  6. swap(A[j], A[j+1])
  7. end if
  8. end for
  9. end for
  10. end procedure
