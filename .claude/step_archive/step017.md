# Step 17 - Awwwards 사이트 선정

## 실행 내용

step013 전체 조사결과를 기반으로, Awwwards 수상작 중 방문할 사이트를 선정한다.

**필요한 파일:**

- step013_조사결과_chunk*.md (전체 조사결과)

## 선정 절차

사전에 고정된 선정 기준을 사용하지 않는다. 다음 절차로 동적으로 결정한다:

1. step013_조사결과_chunk*.md에서 프로젝트의 핵심 특성을 추출한다 (유형, 기능, 대상 사용자, UI 구성 요소)
2. 추출된 특성마다 "이 특성을 잘 구현한 Awwwards 수상작은?" 질문을 생성한다
3. 질문별로 관련 사이트를 탐색한다
4. **특정 카테고리를 사전에 배제하지 않는다** — 프로젝트 특성과의 관련성만으로 판단한다
5. 선정 이유를 사이트별로 명시한다 ("이 사이트를 선정한 이유: 프로젝트의 X 특성과 Y가 유사")

## 결과 저장

`.claude/step017_선정URL.md`에 저장한다:

```markdown
# Awwwards 선정 URL 목록

## URL 1: https://example.com
- 선정 이유: ...
- 조사할 뷰포트: desktop, tablet, mobile

## URL 2: ...
```

서브에이전트는 haiku를 사용한다.
